# bb-plugin-ru-ui

Russian chrome labels for [bb](https://getbb.app).

```sh
bb plugin install .
bb ru-ui status
```

Settings → **Russian UI** → **Translate chrome labels**.

Install:

```sh
# GitLab (корп.)
bb plugin install https://git.sokolov.io/a.agudalin/bb-plugin-ru-ui

# GitHub
bb plugin install https://github.com/Bromisanthrope/bb-plugin-ru-ui
```
